# ブロックチェーン可視化ラボ（デモ）

単一DB・DB＋ハッシュ・ブロックチェーンの3つの記録方式を、シナリオで比べて体験するデモです。
実機には接続せず、ブラウザ上のシミュレーションで動きます。

- シナリオA 正規の更新：`#scenario-a`
- シナリオB データの書換え：`#scenario-b`
- シナリオC 1台の故障：`#scenario-c`
- シナリオD 2台の故障：`#scenario-d`

体験後のアンケート：[`survey/`](survey/)（回答は回答したブラウザに保存されます）

このリポジトリは、卒業研究のデモを書き出した静的ファイルだけを置いています。
